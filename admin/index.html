Import Shopee CSV

From Shopee Affiliate → Product Offer → select items → Batch Get Link → download CSV. Batch caps at 100 rows, so select all your CSVs at once (ctrl/cmd-click) to merge them. No images in that export — items import with a blank thumbnail; edit them in later.

Import Shopee Images

1. Open Shopee Affiliate in Chrome — browse/search products until cards are visible
2. Click the FragLy Extractor extension icon → EXTRACT PRODUCTS → COPY JSON
3. Paste JSON below → PREVIEW → APPLY
Copy Missing List → paste once into the extension's "Missing List" box. It'll then only surface products FragLy actually needs while you browse Shopee — no eyeballing which ones already have photos.

Scan For Blank Images

Some saved images render solid white/blank even though a real URL is stored — usually a video-poster grab or a broken CDN asset. This samples actual pixel color on every saved image and flags ones with near-zero color variation (real photos always have shadows/contrast; a truly blank image doesn't). Review the flagged list before clearing — some products genuinely have plain white packaging.

Auto-Fill Blank Images (Real Product Photos)

Searches each blank product's brand + model (parsed from its name — e.g. "Logitech G402") on Bing Images and stores the top real product photo. Recognizable brands (Logitech, Razer, HyperX…) get the actual product; ultra-niche brands with no web photos are left blank (clean placeholder) instead of a wrong image. Not guaranteed exact — visitors click through to the real Shopee listing anyway. Runs a live search per item, so a full catalog takes a few minutes.

Dead Link Checker

Follows every affiliate link and flags the ones Shopee now sends to its error page — expired or broken short links that send visitors nowhere. Only links that positively resolve to Shopee's error page are marked dead; timeouts and anything unrecognised come back as "unsure" and are never auto-selected, so a network blip can't make you delete a good product. Once done you can deactivate (reversible, hides it from the site) or delete the dead ones in one go. Results are saved on this device, so closing the tab mid-scan doesn't lose them.
Deep check (catches delisted products): the scan above only finds broken short links. A link can still redirect to a normal product page that says "The product doesn't exist" — Shopee serves an identical page and blocks every API for live and dead items alike, so that case is impossible to detect from the server and needs a real browser. Use COPY LINK LIST → FragLy Extractor → Batch Runner → Check for dead links → paste the result back here.
